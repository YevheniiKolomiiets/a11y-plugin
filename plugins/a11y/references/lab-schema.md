# Формат `lab.json`

Дані лабораторії контрасту. Агент пише `lab.json`, `scripts/build-lab.mjs` перевіряє його і вбудовує в `templates/lab.html`. Вся логіка відображення — у шаблоні; у `lab.json` лише дані.

```jsonc
{
  "version": 1,
  "meta": {
    "id": "libertybridge-796",          // стабільний id: ключ для збережених у браузері правок
    "title": "Contrast Lab · 796",       // заголовок вкладки і сторінки
    "project": "Liberty Bridge",
    "audit": "../README.md",            // відносний шлях до звіту аудиту (необов'язково)
    "decisions": "../../specs/796/palette.md", // документ рішень; ставить /a11y:record при першому записі
    "decisionsLang": "uk",              // мова документа рішень; питається при першому записі
    "font": {                            // шрифт застосунку, ним малюються всі зразки
      "stack": "\"Satoshi\", \"Inter\", \"Helvetica Neue\", sans-serif",
      "css": ["https://api.fontshare.com/v2/css?f[]=satoshi@400,500,600,700&display=swap"],
      "note": "fontshare віддає лише 400, 500, 700: semibold рендериться як 700"
    },
    // Звірка з аудитом: скільки пар не проходить у таблицях звіту, по знахідках і темах.
    // build-lab.mjs порівнює з «failing now» рядків, що мають src «аудит» і finding.
    "auditFails": { "light": { "С2": 7, "С5": 2 }, "dark": { "С5": 2, "С6": 1 } }
  },

  // Теми застосунку, скільки завгодно. Порядок = порядок кнопок.
  "themes": [
    { "id": "light", "label": "Світла" },
    { "id": "dark",  "label": "Темна" }
  ],

  // Токени: поточні значення з коду. Кольори, зашиті в компонентах, — теж токени (група «Хардкод → новий токен»).
  // Значення: #rrggbb або #rrggbbaa. Для кожної теми обов'язково.
  // source: де значення оголошено. Об'єкт по темах, якщо кожна тема має свій рядок (CSS-змінні в :root і .dark);
  // рядок — якщо місце одне на всі теми (хардкод у компоненті, одне оголошення).
  "tokens": [
    { "name": "card", "group": "Поверхні", "desc": "Фон карток і модалок",
      "source": { "light": "src/app/globals.css:25", "dark": "src/app/globals.css:97" },
      "values": { "light": "#ffffff", "dark": "#26201d" } },
    { "name": "sev-high", "group": "Хардкод → новий токен", "desc": "text-rose-600 у lib/severity.ts",
      "source": "src/lib/severity.ts:14", "values": { "light": "#ec003f", "dark": "#ec003f" } }
  ],

  // Стартова пропозиція поза рішеннями: те, що вже погоджено або структурно очевидно.
  // Ключі — id тем, значення — { token: hex }. Не перелічені токени = поточне значення.
  "proposal": { "light": {}, "dark": {} },

  // Рядки таблиці. Кольори — посилання на токени: "token", "token@0.1" (додаткова прозорість) або "#hex".
  "rows": [
    {
      "id": "btn-primary",
      "group": "Бренд і посилання",       // заголовок групи; групи йдуть у порядку першої появи
      "label": "Primary-кнопка",
      "where": "ui/Button.tsx:5; Sign In, Save",
      "src": "аудит",                     // аудит | тікет NNN | код
      "routes": ["/login"],               // де елемент рендериться (з elements/*.json)
      "need": 4.5,                        // 4.5 текст, 3 великий текст / іконки / межі
      "kind": "btn",                      // тип зразка, див. нижче
      "text": "Sign In",
      "fg": "primary-foreground",         // колір тексту / іконки
      "bg": ["primary"],                  // шари фону знизу вгору; перший має бути непрозорим
      "stage": ["card"],                  // фон навколо зразка (необов'язково; за замовчуванням bg[0])
      "border": "primary@0.2",            // рамка (необов'язково)
      "size": 14, "weight": 600,          // перевизначити шрифт зразка (необов'язково)
      "hint": "…",                        // пояснення під назвою (необов'язково)
      "themes": ["dark"],                 // рядок лише для цих тем (необов'язково)
      "info": false,                      // true: без порогу (disabled), не входить у підсумок
      "opacity": 0.5, "base": "card",     // CSS opacity всього елемента поверх base (необов'язково)
      "decision": "brand",                // id рішення, якщо рядок у ньому
      "finding": "С3",                    // id знахідки зі звіту аудиту (для рядків з src «аудит»)
      // Чому жоден вибір кольору цього не виправить (структурна зміна, формула в коді).
      // Без нього рядок, що не проходить у пропозиції і не входить у рішення, збірка друкує як «без рішення».
      "noDecision": "колір аватара береться з імені: змінювати формулу, а не токен",
      // Що виміряв аудит, коли код показує інше, ніж оголошує (структурний дефект).
      // Колонка «Зараз» бере ці числа; «Пропозиція» — кольори з палітри, ніби дефект виправлено.
      // Без ratio (лише note) — нічого не малюється: рядок зараз не проходить.
      "measured": { "light": { "ratio": 2.24, "fg": "#577e9e", "bg": "#0f4775", "note": "лише ripple" } }
    },
    {
      "id": "ring-contained",             // kind focus: кільце фокусу навколо справжнього контролу
      "group": "Кільце фокусу",
      "label": "Contained-кнопка: Continue",
      "need": 3,
      "kind": "focus",
      "fg": "primary",                    // колір кільця
      "bg": ["card"],                     // поверхня навколо контролу
      "control": {                        // сам контрол; без bg — прозорий (поверхня)
        "shape": "btn",                   // btn | item (пункт списку/меню) | icon | toggle (сегмент групи з overflow: hidden: зовнішнє кільце обрізається зверху і знизу — видно у зразку)
        "bg": ["primary"], "fg": "primary-foreground", "border": "primary@0.5", "text": "Continue",
        "groupBorder": "border"           // лише toggle: рамка групи
      },
      "offset": 2, "width": 2,            // outline-offset і ширина, px; від'ємний offset — кільце всередині контролу
      "icon": "close"                     // для shape icon
    }
  ],

  // Рішення: групи рядків з варіантами. Варіант — набір значень токенів по темах.
  "decisions": [
    {
      "id": "severity",
      "title": "Impact priority HIGH / MEDIUM / LOW",
      "themes": ["dark"],                 // необов'язково: рішення лише для цих тем; в інших його рядки — звичайні
      "status": "open",                   // open | recorded (ставить /a11y:record, коли записано ВСІ теми рішення)
      "chosen": {},                       // записані теми: { "light": "A" }; тема без ключа ще відкрита.
                                          // Рядок ("A") — усі теми одразу (старі дані). Якщо користувач
                                          // підправив кольори — /a11y:record додає варіант
                                          // { "id": "manual", "manual": true, "from": "<X>", … } і обирає його для цієї теми
      "options": [
        { "id": "A", "label": "Той самий відтінок, крок темніше / світліше",
          "tokens": { "light": { "sev-high": "#c70036" }, "dark": { "sev-high": "#ff637e" } } }
      ]
    }
  ],

  // SVG для зразків kind=icon: row.icon = ім'я ключа. stroke="currentColor".
  "icons": { "chat": "<svg viewBox=\"0 0 24 24\" …>…</svg>" }
}
```

## Як рахується пропозиція

Для кожної теми значення токена в колонці «Пропозиція» береться за першим збігом:

1. правка користувача в палітрі (зберігається в браузері);
2. варіант, обраний у рішенні (клік по картці або `chosen` у записаному рішенні);
3. `proposal` з `lab.json`;
4. поточне значення з `tokens`.

Відкрите рішення без вибору показує в кожному своєму рядку картки всіх варіантів.

## Типи зразків (`kind`)

| kind | Що малює | Особливі поля |
| --- | --- | --- |
| `text` | звичайний текст 12px | |
| `tiny` | дрібний текст 9px | |
| `eyebrow` | uppercase підпис 11px bold | |
| `display` | великий заголовок 40px | |
| `link` | посилання | |
| `link-icon` | посилання з іконкою зовнішнього переходу | `size` |
| `btn` | кнопка: текст `fg` на заливці `bg` | `stage`, `border` |
| `edge` | межа компонента відносно фону: заливка `fg` на `bg` | `inner` — токен тексту всередині |
| `chip` | чіп-тег uppercase 10px | `border` |
| `badge` | пігулка 12px semibold | `border`, `stage` |
| `sev` | маленький бейдж uppercase 9px black | `stage` |
| `pill` | лічильник 10px bold | `stage` |
| `plate` | плаваюча плашка 8px | `border` |
| `avatar` | круглий аватар з ініціалами | `text` = ініціали |
| `icon` | SVG-іконка на своєму `bg`; із `stage` — плашка `bg` усередині `stage` | `icon` — ключ з `icons` |
| `input` | поле з плейсхолдером; контраст плейсхолдера `fg` | `border` |
| `field` | межа поля (1.4.11): рамка кольору `fg`, заливка й фон навколо — `bg`; контраст рамки до `bg` | `inner` — токен плейсхолдера |
| `footer` | текст 10px | |
| `in-row` | бейдж усередині тонованого рядка | `stage` = фон рядка |
| `focus` | контрол (`control`) на поверхні `bg` з кільцем `fg` як `outline`; контраст — гірша пара з кільце / поверхня і кільце / контрол, за `offset` і `width`; з `measured` у колонці «Зараз» контрол без кільця | `control`, `offset`, `width`, `icon` |
| `stack` | кілька рядків тексту з різним кольором і жирністю | `parts: [{ "text", "fg", "weight", "proposalWeight" }]`; контраст рахується за `fg` рядка; `proposalWeight` — жирність у колонці Proposal, якщо рішення її змінює |
| `logo` | словесний знак лого з частин різного кольору, стовпчиком 26px | `parts: [{ "text", "fg" }]`, `fontFamily`, `italic`; контраст рахується за `fg` рядка |

Розмір і жирність за замовчуванням задає тип; `size` / `weight` у рядку їх перевизначають.

## Що копіюється з картки варіанта

Вибір робиться для теми, яку користувач зараз бачить; в інших темах рішення лишається відкритим, і копіюється лише ця тема:

```text
[a11y:lab] decision=severity theme=light option=A
light: --sev-high #c70036, --sev-medium #a65f00
```

Якщо користувач змінив токени рішення після вибору — `option=A (edited)` і поточні значення.

Кнопка **Copy all choices** у шапці копіює всі вибори поточної теми, ще не записані в `lab.json`, — такі самі блоки, розділені порожнім рядком.
